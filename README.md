# FindABook
(Academic project) 

FindABook is a web based online bookstore application developed to support the main operational activities 
of a digital book retail business. The system provides a customer facing storefront together with 
administrative functions for managing books, authors, categories, customers and orders. Customers can 
create accounts, verify their accounts, sign in, browse and search for books, maintain a Wishlist, manage a 
shopping cart, complete checkout and review order information. Administrative users are provided with 
dedicated access to manage catalogue information and monitor operational data. 
The implementation uses a Java based enterprise web application architecture. The project contains Java 
REST style controllers, service layer business logic, Hibernate ORM entity mappings, MySQL database 
connectivity, JavaScript client side functionality, JSON based communication, session and cookie handling, 
email services, file uploading and dashboard/reporting queries. The project source contains entities for 
users, roles, statuses, books, authors, categories, addresses, cities, carts, orders, order items, payments and 
Wishlist.
